Features

what it does
Multi-cloud

Six sources, one place

AWS and Alibaba Cloud provide billing APIs; DeepSeek provides a balance API. Import bill exports from Alibaba Cloud, Volcengine, OpenAI, Anthropic and DeepSeek for spending detail. Azure and Google Cloud are not currently supported.

Import

Bring your own bill

Import a provider export into the same ledger used by API data, including model and token detail where available. Imports replace whole months for the selected account; Refresh and Force Refresh preserve them. Token-only exports remain usage records, not estimated bills.

Schema

A shared billing vocabulary

Sources normalize into a fact table named after FOCUS columns, with separate categories for usage, credits, refunds, taxes and fees. CloudBridge uses this vocabulary; it does not implement the full FOCUS specification.

Overview

Usage and net, kept apart

Explore month-to-date, rolling 30-day or 12-month trends. The headline total is net of credits, while charts, rankings and biggest movers show gross usage so credits do not hide changes in consumption.

Security

Credentials in the OS keyring

Saved credentials live in the OS keyring, separate from the billing databases, and authenticate direct provider requests. There is no CloudBridge sync service or telemetry. Billing and raw files are local, but not encrypted by the app.

Refresh

Reduce repeated API calls

A 24-hour freshness window avoids repeatedly fetching the same billing period; choose 6, 12, 24 or 48 hours in Settings. Each Cost Explorer query covers one period, so a refresh that needs several periods sends several requests. Force Refresh bypasses the window and can add provider charges.

Interface

A native desktop tool

Built on GPUI, Zed's GPU-accelerated framework, with a compact desktop interface and light and dark themes.

Alerts

Rules that watch the ledger

Review unusual daily spend, low prepaid balances and a growing share of unallocated usage. Alerts include the figures behind each condition and projections where available. Rules do not run while the app is closed.

Attribution

Where the money went

A Sankey from source to service to business line, with an explicit Unallocated node — the share of the bill you cannot yet explain is a number on the page, not an omission from it.

How it works

three steps
01

Download & install

Download the official release for Windows x64 or macOS Apple Silicon. On macOS, drag the app from the disk image to Applications; on Windows, run the executable.

02

Add accounts, or a bill

For a source with a billing API, enter the credentials — they go straight into your OS keyring, never into the database. For a source you import from, there are no credentials to enter: add the account and hand it the file.

03

Read the ledger

Open the Overview for totals, trends and the biggest movers, over the range you pick.

FAQ

answers
Can I try it before installing anything?
Yes. The same application compiles to WebAssembly and runs at the browser demo, on a sample bill of twelve months across AWS, Alibaba Cloud and DeepSeek. The pages, the charts and the alerting rules are the desktop build's own code. What it cannot do is the part that needs your machine: it holds no credentials, calls no billing API, imports no bill file and has no SQL console. Nothing you do in it is saved.
Is CloudBridge free to use?
Yes. CloudBridge is free and open source under the MIT license. Provider fees are separate: AWS Cost Explorer charges per API request, and total cost depends on accounts, periods and refreshes. There is no fixed daily cost guarantee. Local file imports do not call billing APIs.
How is my data secured?
Saved credentials are held in the OS keyring and authenticate requests directly to configured providers. There is no CloudBridge sync service or telemetry. The app does not encrypt the local ledger or raw billing files: use OS disk encryption, protect backups, and redact credentials and billing identifiers before sharing data.
Which cloud providers are supported?
AWS and Alibaba Cloud provide billing APIs. DeepSeek provides a balance API and file imports for spending detail. Alibaba Cloud, Volcengine, OpenAI and Anthropic also support bill imports. Azure and Google Cloud are not currently supported. Unreleased: the development tree supports AWS Data Exports from S3; see the changelog for release status.
Can I use a bill I downloaded instead of an API key?
Yes. File imports need no credentials and can provide more detail than the billing API. Add an account, select Import bill on its row, and choose a supported export. An import replaces every month it covers for that account, so export the full bill rather than a product-filtered subset. Refresh and Force Refresh preserve imported months. See the import guide.
What is FOCUS, and why does it matter?
FOCUS is an open specification for cost and usage data. CloudBridge's ledger is named after FOCUS columns, giving provider data a shared vocabulary for billed cost, effective cost and charge categories. This is not a full implementation of the specification, and each supported export needs its own parser. The Foundation's adoption guide explains the specification.
What IAM permissions does CloudBridge need?
Use least-privilege credentials for provider reads. The AWS Cost Explorer policy grants only ce:GetCostAndUsage; STS account validation requires no additional permission grant. S3 exports require separate bucket permissions. Alibaba Cloud uses AliyunBSSReadOnlyAccess. An API key's permissions depend on its provider and configuration; using it for balance queries does not make it read-only. See permission templates.
Does CloudBridge work on Linux?
Published builds cover Windows x64 and macOS Apple Silicon. Linux and Intel Mac binaries are not published, and source builds on those platforms are not guaranteed to work. Consult the contributing guide linked above for development prerequisites and validation guidance.
How often is cost data refreshed?
Refresh uses a 24-hour freshness window by default; Settings offers 6, 12, 24 or 48 hours. Refresh fetches stale API-backed periods, while Force Refresh bypasses the window and can incur additional provider charges. Neither replaces an imported month; re-import a corrected export to update it. Provider reporting delays still apply.
Can I export my cost data?
You can query the local DuckDB ledger directly. Provider responses and imported files are retained under raw/; see storage and backups before copying or sharing them. Reading provider exports is a separate feature: AWS Data Exports from S3 is Unreleased, and OSS collection remains on the roadmap.
